# Insurance Charges Prediction
## problem
predict medical insurance charges based on patient data

## Dataset
1338 patients with age, sex, bmi, smoker, region, charges

## key insight
smokers pay $24,000 more than non-smokers!!

## Models Used 
-Linear Regression - 72% accuracy
-Random Forest     - 85% accuracy

##Libraries
pandas , sklearn, matplotlib, seaborn
